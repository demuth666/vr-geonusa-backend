# Version learning experiences and keep ML identification non-gating

Each research study defines a Learning Experience for a heritage site, and every Learning Session is permanently pinned to an immutable published revision so that later content edits cannot change an active or completed research protocol. A revision explicitly selects required panorama visits, learning materials, and Micro Quizzes; quiz completion requires a fully answered submitted attempt rather than a passing score. ML Identification is expected and recorded but does not gate V1 completion, allowing the learning journey to continue when camera support, inference, or the ML service is unavailable.

## Consequences

Administrators prepare changes as drafts and publish replacements instead of modifying published revisions. Existing sessions continue using their pinned revision, while new sessions use the newly published revision. Micro Quiz feedback may be immediate, but each answered question is immutable within an attempt and retries create a new attempt.
